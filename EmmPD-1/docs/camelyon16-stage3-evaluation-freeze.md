# CAMELYON16 第三阶段：评价协议设计复审稿

**版本：** 1.0
**日期：** 2026-10-12
**状态：** 设计方向已由用户确认；XML 修复复核收据流程已实现，服务器端测试、复核及最终冻结尚未完成，故目前不是已冻结协议。

本协议定义 CAMELYON16 Stage-1 的评价单位、病灶几何、区域预算、指标、模型选择、统计报告和测试集隔离。协议与评估器、合成几何验收及 E/F 预测导出全部对齐后，才能正式冻结和启动基线训练。

## 1. 研究问题与结论边界

主要问题是：在相同的双图 Query 模型中，加入 XML 定位监督后，模型能否在固定候选 patch 面积预算内覆盖更多净肿瘤标注区域？

- 唯一主比较为 D−C。两组除 XML 定位损失开关外，模型结构、训练数据顺序、优化器、损失缩放、训练预算和验证选择规则相同。
- 唯一主终点为切片等权的病灶宏平均面积覆盖率@5%，简称 MLAC@5%。
- 主结果衡量的是固定面积预算下的标注区域覆盖改善。它不单独证明独立病灶检出数增加，也不证明 token 是可信的连续病灶区域。
- D−E、C−B、E−B、F−E 及 1%/10% 预算结果作为预先规定的次要描述。A 只用于切片分类比较，不报告空间 evidence、token 或病灶指标。
- 本数据划分来自 CAMELYON16 原始训练 WSI，不是官方独立测试集。100 个 patient_id 未经核实；清单中与 slide_id 相同的字符串不得当作患者身份。结果只支持切片级内部留出，不支持患者级独立验证或外部泛化。

## 2. 评价样本、坐标和候选 patch

### 2.1 样本范围

评价只纳入 annotation_status 为 full 的阳性切片及正常切片。部分标注、缺失标注、XML 解析不完整或组别无法解释的切片不得按完整阴性背景计入病灶评价。

本地清单快照记录 60 张 full 阳性切片、40 张正常切片，固定 train/validation/test 为 60/20/20；测试部分对应 12 张阳性和 8 张正常切片。CAMELYON16 维护说明列出的非穷尽标注切片不在本地选择的 60 张阳性片中。数据来源语义见 [CAMELYON16 README16](https://github.com/hansbu/camelyonChallenge/blob/master/README16.md)。

### 2.2 候选集合与几何验收

候选 patch 集合由固定组织筛选和特征提取流程产生，不得因 XML、模型、分数或测试表现改变。候选集合包含所有 H5 中的 patch，XML 仅用作训练监督或冻结后的评价真值。

当前提取代码以 patch_size_level0 为步长生成方块，预期同一切片内方块等大且内部不重叠。正式冻结前必须逐一核验 100 个 H5：

1. patch_size_level0 从 H5 属性读取且大于零；不能依赖本地 CSV 中可能为零的字段。每张切片 N_i 必须大于零。
2. 坐标唯一、位于 WSI 范围内，且方块具有相同边长；每个 x、y 坐标均为 patch_size_level0 的整数倍。
3. 方块内部不重叠；边缘接触允许。
4. 坐标、H5 属性与提取配置一致；不符合时中止冻结并追查数据来源。

对切片 i，候选方块记为 P_ij，数量为 N_i，方块并集为 U_i。验收通过后，|U_i| 等于 N_i 个 patch 方块面积之和。候选组织 mask 不是病理组织精确分割，因此 5% 的分母表示候选 patch 方块面积，不表示染色组织的精确面积。B、C、D、E 的排序分数固定为模型输出的 evidence_scores；F 使用线性 patch 头的原始 logit z_j。A 不进入空间排序评价。

## 3. XML 病灶的操作性定义

### 3.1 组别和排除区

CAMELYON16 维护说明将原始组 _0、_1 定义为肿瘤，将 _2 定义为从肿瘤标注中切出的非肿瘤区域。本地 XML 实际声明的组名只有 `Tumor` 和 `Exclusion`。用户确认本数据导出中的 `Exclusion` 对应源组 `_2`；冻结记录需注明这是用户提供的来源映射，XML 本身不能证明转换链。评价器同时支持这两套已知组名，拒绝未知组。

按上述已声明语义解析后：

- 肿瘤原始几何为所有 _0 与 _1 多边形的并集。
- 排除几何为所有 _2 多边形的并集。
- 净肿瘤几何 T_i 为肿瘤原始几何减去排除几何。
- _2 区域是有效非肿瘤背景，参与有效负例、预算纯度和假阳性评价。
- 未知组、未映射组或含义冲突的 XML 必须报错并进入人工核查，不可默认为负例。

### 3.2 几何修复和病灶拆分

几何统一使用 WSI level-0 矢量坐标和精确多边形面积，不栅格化。

- XML 多边形无效时使用固定的 make_valid 修复；记录原始有效性原因、XML 校验值、标注序号、坐标范围、顶点数、修复前后面积、几何类型和产生的多边形部件。审计会汇总全部修复并输出 `needs_review`。每条修复都须检查 WSI 局部图并在复核 CSV 中作出决定；`accept_make_valid` 仅表示几何修复符合原画线，不表示病理性质确认。其他决定会阻断收据和冻结；不得为通过验收而修改原始 XML。修复面积差很小本身不足以放行，因为病灶拓扑和连通分量数也可能改变。
- 修复后只保留正面积的多边形部件，不进行平滑、简化或最小面积筛除。
- 净肿瘤几何拆成拓扑连通分量。两个部件只要共享边或点即视作同一病灶；相距任何正距离的部件保持分离。
- 病灶分量按最小 y、最小 x、面积、规范化几何编码稳定排序后编号。病灶是本研究的操作性几何单位，不等价于临床独立转移灶。

点接触合并可能把由标注误差造成的细小桥接看作同一病灶。主分析不按模型结果调整拆分规则；如果需要报告替代连通规则，只能在查看测试预测前登记为敏感性分析。

`scripts/render_stage3_xml_repairs.py` 按审计报告和 XML 校验值生成每处修复的 WSI 局部图、联系表及待审核 CSV。正式复核须一次覆盖所有含修复的 train/validation/test 切片，并在测试预测前进行。收据程序将审核队列与审计修复清单逐条比对，检查切片、XML 哈希、标注序号和几何元数据；它拒绝缺失、重复、过期或未接受的行。`scripts/accept_stage3_repairs.py` 输出带审核人、时间、清单哈希和队列哈希的收据。该收据是审核声明，不是数字签名。

审核只回答给定 `make_valid` 的修复轮廓是否符合原始画线；不判断组织学性质，不将多边形部件数当作病灶数，也不改变 XML。若画线意图无法判定，应保留未解决状态并追查标注来源；不能把它批量确认为正确。

### 3.3 patch 标注

每个候选 patch 的连续肿瘤比例为其方块与净肿瘤几何交集面积除以方块面积。二值 patch 标签固定为连续比例大于或等于 0.5。边界 patch 不删除，连续比例保留用于面积覆盖和 Query 诊断。

正常切片候选 patch 全部是有效负例；full 阳性切片候选 patch 全部依据完整 XML 标注为有效区域，包括 Exclusion。部分或缺失标注切片不得把未知区域计作负例。

## 4. 主终点：MLAC@5%

对每张 full 阳性切片 i，令 L_i 为净肿瘤连通分量数，G_iℓ 为第 ℓ 个病灶。模型 s 的 patch 证据分数在该切片内降序排序；相同分数按 y、x、patch 序号稳定排序。

取 k_i = floor(0.05 × N_i) 个最高分 patch，所选方块并集记为 R_is。主预算严格是候选 patch 方块并集面积的 5% 上限。实际预算 k_i/N_i 必须随结果输出。若 N_i 小于 20，则 k_i 为零、主覆盖率记为零，并记录该切片的零预算情况；不得通过强制多取一个 patch 超过预算。

单切片、单种子的病灶宏平均覆盖率为：

m_is = (1 / L_i) × Σ_ℓ [ area(R_is ∩ G_iℓ) / area(G_iℓ) ]。

未被任一候选 patch 覆盖的病灶仍留在 L_i 和分母中，覆盖率为零。可达覆盖上限为：

u_i = (1 / L_i) × Σ_ℓ [ area(U_i ∩ G_iℓ) / area(G_iℓ) ]。

u_i 不施加 5% 预算，只描述候选 patch 对每个病灶的几何可达程度。训练、验证和冻结后的测试输出均应逐片报告；不可达病灶不从主指标中删除。

三个固定种子的主效应先在每张切片内配对平均，再对阳性切片等权平均：

d_i = (1 / 3) × Σ_s (m_i,s,D − m_i,s,C)；
Δ = (1 / n) × Σ_i d_i。

主指标名称、病灶宏平均层级、切片等权方式和完整病灶分母均须保留在预测与指标产物中。

1% 和 10% 预算使用相同候选集合、floor 规则、分数并列顺序和病灶分母，只作为次要敏感性结果，不能替代主预算。

## 5. 模型无关参照与配套定位指标

### 5.1 随机选区@5%

在方块等大且不重叠、k_i 固定的条件下，从 N_i 个候选 patch 中均匀随机选 k_i 个。MLAC 的随机期望可精确计算为：

Random_i@5% = (k_i / N_i) × u_i。

该参考不需要模型训练或随机模拟，不参与 checkpoint 或方法选择。

### 5.2 XML oracle@5%

对每个候选 patch j，计算其对病灶宏平均目标的覆盖增益：

gain_ij = (1 / L_i) × Σ_ℓ [ area(P_ij ∩ G_iℓ) / area(G_iℓ) ]。

按 gain 降序取 k_i 个 patch，平分按 y、x、patch 序号。由于候选方块等大且不重叠，覆盖增益对被选方块可加；取前 k_i 个是该候选集合和预算约束下的精确最优解。因此可以称为 XML oracle 上界。

XML oracle 使用真值，只作为评价参照，不得用于训练、checkpoint 选择、阈值确定、模型调整或候选集合生成。

### 5.3 配套区域指标

- Purity@预算：所选方块内净肿瘤面积 / 所选区域总面积；逐阳性切片宏平均，预算为空时为 NA。
- 总肿瘤面积覆盖：所有阳性切片被所选区域覆盖的净肿瘤总面积 / 所有阳性切片净肿瘤总面积，作为面积加权配套结果。
- 1%、5%、10% 的实际预算、u_i、MLAC 和 purity 均逐片保存，不只报告跨片均值。
- 面积覆盖只度量真值区域交叠，不把分数解释成概率，也不把离散的 attention 直接称为连续分割区域。

### 5.4 Patch、切片与 Query 指标

- Patch AUROC 和 AUPRC 按切片分别计算；该片标签必须同时包含正、负 patch。单类别切片两指标均为 NA，不记零。
- 宏平均只纳入可计算切片，同时报告可计算数、总切片数及 NA 数。跨所有有效 patch 的 pooled 指标可作描述性补充，不把 patch 当独立统计样本。
- 已知有 3 张肿瘤切片没有 tumor_fraction ≥ 0.5 的 patch；这些切片的 patch AUROC/AUPRC 为 NA，但仍进入 MLAC、u_i 和病灶级分母。
- 切片分类报告 AUROC、AUPRC。敏感度和特异度阈值只在 validation 按 Youden J 选择，测试时固定；并列选择较高阈值。没有外部依据时不定义分类非劣效界值，不宣称“分类能力保持”。
- A 没有经训练的空间 evidence 输出，不报告 patch 定位、FROC、token purity 或 Query 指标。
- 对有 Query 的模型，attention mass purity 用连续 tumor_fraction 计算；病灶 attention mass 使用 patch 方块与每个病灶的精确交叠比例加权。一个病灶若至少被一个 Query 分配 10% attention mass，则记为被 attention 覆盖。Query redundancy 为 Query attention 向量两两余弦相似度的非对角均值。这些是诊断指标，不用于 checkpoint 选择。

## 6. 自定义病灶级 peak-FROC

连通组件方案会让单个大组件同时命中多个病灶，故不用于本协议的病灶级 FROC。改用基于 patch 局部峰值的自定义 peak-FROC；不得称作官方 CAMELYON FROC。

1. 对每张切片的候选 patch 中心构建固定网格。只比较坐标相差一个 patch_size_level0 的八邻居；缺失的非组织 patch 不补造预测节点。
2. B、C、D、E 使用各模型输出的 evidence_scores；F 使用 patch 线性头原始 logit。一个 patch 分数不低于所有有效八邻居时为局部峰。完全相等且相连的平台合并成一个峰，平台内选距几何质心最近的 patch，平分按 y、x、patch 序号稳定排序。
3. 峰中心使用 patch 方块中心坐标。中心被净肿瘤几何覆盖时归属该病灶；几何边界按覆盖处理。若同一病灶有多个峰，最高分峰为该病灶唯一 TP，其余为重复 FP。所有不属于任一病灶的峰均为 FP。
4. 峰与病灶的归属先按分数、切片 ID、病灶 ID、y、x 的稳定规则确定；随后只需按唯一峰分数排序一次，累积生成阈值曲线，不在每个阈值重复构图。
5. 阈值集合是所有峰分数的唯一值，并加入无预测点；并列分数在同一阈值同时纳入。
6. 预设 FP/slide 目标为 0.25、0.5、1、2、4、8。FP/slide 分母包含完整 test 中的阳性和正常切片；敏感度分母包含这些阳性切片 XML 中的全部净肿瘤病灶。
7. 每个目标报告所有满足 FP/slide ≤ 目标值的操作点中的最大敏感度；重复 FP 横坐标取最高敏感度，不插值、不外推。若观测曲线未达到目标，明确报告目标未达到及观测最大 FP/slide。
8. 六个目标的敏感度均值称为预设网格平均敏感度，不称为曲线下面积。FROC 是次要描述，不参与 checkpoint 选择。

局部峰方法的风险是组织掩膜边缘、缺失 patch 网格和很小病灶会影响峰数量或位置。合成样例及真实训练/验证规模检查必须覆盖这些情形；测试预测不得用于更改峰规则。

## 7. 模型组、训练控制和 checkpoint 选择

| 组别 | 定义 | 可报告范围 |
|---|---|---|
| A | 普通 pooling，无 XML 定位监督 | 切片分类 |
| B | Query，无图、无定位监督 | 分类和空间 evidence 诊断 |
| C | 双图 Query，无定位监督 | 分类和空间 evidence |
| D | 双图 Query，加 XML 定位监督 | 分类、主定位及配套定位 |
| E | Query，无图，加 XML 定位监督 | 分类和配套定位 |
| F | 冻结 UNI 特征上的线性 patch 分类头，加 XML 定位监督 | 分类和配套定位；作为简单结构参照 |

所有组共用 split manifest、冻结 UNI 特征、XML 连续标签、完整阳性切片、AdamW 优化器、learning rate=0.0001、weight decay=0.0001、gradient clip=5.0、最多 50 epoch、patience=10 及三种子 9233、9234、9235。每个 epoch 按 manifest 行顺序逐片训练，每张切片一次 optimizer step；不打乱、不使用由 XML 改变的病灶过采样。每张切片的定位损失对该片有效 patch 求均值，再对训练切片求均值，避免 patch 多的 WSI 获得更高样本权重。分类损失权重只由训练 split 的切片类别频数计算，所有组和种子使用同一公式及配置。

D、E、F 使用相同连续 tumor_fraction 目标和相同定位损失系数 λ_loc=1.0。定位损失是对有效 patch 的连续 BCE，先在单片 patch 维度求均值，再在切片维度求均值。C 与 D 的唯一有意差别是定位损失系数为零或 1.0，故 D−C 才是主监督效应。Query 组的多样性损失固定为零，除非另行预注册新实验。

F 使用每个 UNI patch 的线性 logit z_j，patch 概率为 sigmoid(z_j)，切片 logit 固定为所有候选 patch logit 的最大值。切片二分类 logits 表示为 [-z_slide/2, z_slide/2]，以便沿用共同分类损失。F 的 patch 定位损失使用与 D/E 相同的连续目标和逐片平均规则。F 与 D/E 可比较同等标签来源和损失权重下的简单结构基线；其 max-MIL 聚合机制不同，因此不得把 F−E 单独解释为某一模块的纯因果效应。

所有模型按 validation 切片 AUROC 选择 checkpoint。比较前将 AUROC 四舍五入到 6 位小数；提升必须严格大于当前最佳舍入值，平分保留最早 epoch。最多 50 epoch，连续 10 epoch 没有提升则停止。记录 checkpoint epoch、精确与舍入 AUROC、训练损失、验证定位曲线，但定位曲线不参与选择。

该规则回答“采用分类导向模型选择时，XML 监督是否改善定位”，不回答各模型自身最佳定位能力。validation 只有 20 张切片，AUROC 可能并列；最早 epoch 规则可能偏向较早模型。训练过程和验证损失曲线要保留，不能通过测试结果换 checkpoint。

训练入口只加载 train 与 validation。测试 H5、XML 标签、预测和叠图由独立评估入口在协议、配置和评估器哈希冻结后读取。训练代码不得加载 test split，也不得把测试指标或测试 XML oracle 传回训练和模型选择。

## 8. 统计报告

- 主点估计为 Δ；测试集有 12 张阳性切片，区间以这 12 张阳性 test 切片为抽样单位做 10,000 次配对 percentile bootstrap，固定 bootstrap seed=9233，报告 2.5% 与 97.5% 分位数。
- 每次重采样一个切片时，保留该切片全部模型和三个种子的配对记录；先算该片三种子平均差，再汇总切片。不得把“切片 × 种子”、patch、Query 或病灶展平为独立统计样本。
- 另报三个单种子 D−C 效应的均值、标准差、最小值和最大值。三个种子是有限训练重复，不是充分的随机性估计。
- 95% 区间主要表示给定三个训练结果下的切片抽样不确定性。patient_id 未核实，因此不能声称患者聚类区间；若一个患者贡献多张切片，切片 bootstrap 可能低估不确定性。
- 唯一确认性效果量为 D−C MLAC@5%。所有次要比较、指标和预算点只报告效应量、逐片结果和配对区间，不计算或筛选次要 p 值；因此本协议没有事后扩张的 Holm 校正集合。
- 小测试集的宽区间应如实报告。不能把种子波动解释为切片样本量，也不能用“差异不显著”推断两模型等效。

## 9. 评估器合成验收与规模验收

在任何 test 预测前，评估器须通过人工构造的几何与分数样例，并把输入、预期结果和实际结果保存为版本化验收记录：

1. 无覆盖病灶：MLAC=0，病灶仍在分母。
2. 完全覆盖病灶：MLAC=1；候选可达上限 u_i=1。
3. 候选覆盖不完整病灶：主覆盖分母保留全病灶，u_i 精确小于 1。
4. Exclusion 孔洞：孔洞面积不计入净肿瘤；选区落在孔洞中降低 purity，病灶覆盖不把孔洞算作肿瘤。
5. 方块重叠：主 H5 几何验收应拒绝重叠；通用几何辅助函数仍须验证并集面积不重复累加。
6. 预算并列、恰好用满、剩余面积不足一个 patch、N_i<20：排名稳定，实际预算正确，不超 5%。
7. 极小病灶和边界病灶：不按面积删除；交集面积、中心点覆盖和病灶归属符合矢量几何预期。
8. 正常切片：病灶数为零，所有峰均计 FP，FROC FP/slide 分母包含该片。
9. 同一病灶多个峰：最高分峰计一个 TP，重复峰计 FP；不同病灶不可被单个峰重复命中。
10. 单类别 patch 标签：AUROC/AUPRC 为 NA，并在有效样本计数中明确体现。

规模验收在 train/validation 的全量真实 patch 数上运行，记录 wall time、峰数量、内存和输出一致性。若复杂度或内存不适用于完整评估规模，先优化实现；不得通过减少测试候选或抽样测试 patches 改变协议。

## 10. 输出、审计和测试隔离

每个模型、种子、split 保留：

- run 配置、split manifest SHA-256、UNI 特征来源与哈希、XML parser 与评估代码版本；
- 所选 epoch、训练历史和 validation 选择指标；
- 每片 slide 分数、分类概率、patch 坐标、patch 分数、tumor_fraction、标签有效位；
- 每片 N_i、k_i、实际预算、每病灶 MLAC、u_i、purity、随机参照和 XML oracle；
- Query 模型的 attention/token 权重与 Query 诊断指标；
- peak 坐标、峰分数、TP/FP/重复匹配原因和完整阈值曲线；
- AUROC/AUPRC 的有效切片数、NA 数及所有配对统计输入。

测试集可在训练前按冻结规则做数据完整性和坐标检查，不看预测热图、模型指标或 XML oracle 结果。协议版本、split manifest、配置、特征清单、修复审核收据和评估代码哈希锁定后，独立评估入口运行一次。测试评估器验证收据哈希及当前 XML 哈希；验证或训练评估遇到修复标注时也必须使用同一冻结收据。实现错误修复只能保持本协议定义不变；任何定义变化须形成新协议版本，并在打开测试预测前完成。
